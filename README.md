# EpicEventMineBlaze: анимированный лендинг

Статический сайт с правилами турнира BedWars 2×8. Турнир: 24.10.2026, 17:00–21:00 МСК, призовой фонд 2 000 рублей. Без базы данных, регистрации, сборки, библиотек и внешних запросов. Все ресурсы находятся в архиве.

## Просмотр

Распакуйте архив и откройте index.html. Для более точной проверки можно запустить в папке сайта `python -m http.server 8080` и открыть http://localhost:8080. Копирование в буфер работает на HTTPS и localhost. При недоступном буфере сайт открывает окно с текстом правил.

## GitHub Pages

В репозитории уже добавлен workflow `.github/workflows/pages.yml`. После включения GitHub Pages с источником **GitHub Actions** сайт будет публиковаться автоматически при каждом обновлении ветки `main`. Ожидаемый адрес: `https://inpeacedTeams.github.io/EpicEventMineBlaze/`.

Если GitHub попросит выбрать источник, открой Settings -> Pages -> Build and deployment -> Source -> GitHub Actions.

## Cloudflare Pages

Создайте проект Pages с прямой загрузкой статических файлов (Direct Upload). Загрузите распакованное содержимое папки, чтобы index.html находился в корне публикации. Для этого сайта не нужен Worker, Supabase или команда сборки. При Git-развёртывании выберите статический проект без сборки и укажите корень с index.html как папку публикации.

_headers задаёт защитные HTTP-заголовки для Cloudflare Pages.

## Изменения

index.html: тексты, секции, ссылки.
style.css: цвета, адаптивная вёрстка, анимации.
app.js: появление секций, прогресс прокрутки, копирование правил. При изменении регламента обновите также текст rules в app.js.
assets/emblem.svg: локальная векторная эмблема организации.

На лендинге указаны подтверждённые детали: 24.10.2026, 17:00–21:00 МСК, призовой фонд 2 000 рублей. Автокликеры разрешены согласно переданным правилам турнира. Лендинг не проверяет совместимость регламента с правилами сервера.

Анимации отключаются для посетителей с системной настройкой уменьшения движения. Основной контент, якоря и раскрывающиеся ответы доступны без JavaScript. Для копирования правил требуется JavaScript.
